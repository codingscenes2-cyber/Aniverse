UNDER THE HOOD

Lean frontend. Live catalogue.

The current product is a React web application that queries AniList directly for catalogue information.

Frontend

React + TypeScript with a Vite-based app structure, responsive CSS, and Lucide iconography.

Catalogue API

AniList GraphQL provides anime lists, details, characters, staff, relations, recommendations, airing data, and external links.

Personal storage

Watchlist entries, status, and episode progress are saved in browser localStorage. No account sync is currently included.

ReactTypeScriptViteAniList GraphQLlocalStorageResponsive CSSLucideGitHubAppDeploy
Important boundaries: ANIVERSE is a discovery and tracking product, not a video host. It does not stream or download anime episodes. External viewing links appear only when catalogue data provides them. Cast, staff, episode, and provider coverage varies by title. Library data is browser-local and is not yet account-synced.

Ideas on the ANIVERSE horizon.

01 · Smart discovery engine

Preference-aware recommendations using genres, favourites, completed shows, ratings, watch history, and explicit “more like this / less like this” feedback.

PROPOSED

02 · Account & cloud sync

Optional sign-in, cross-device library sync, backup/restore, profile privacy controls, and conflict-safe progress updates.

PROPOSED

03 · Advanced watch planner

Weekly watch schedule, release reminders, seasonal watch calendar, backlog prioritization, and progress streaks that users can disable.

PROPOSED
