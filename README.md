# ANIVERSE

A cinematic anime discovery and watchlist experience powered by the public AniList GraphQL API.

## Features
- Live anime discovery, trending titles and seasonal picks
- Search by title and filter by genre
- Sort by popularity, score, trending and release date
- Anime detail profiles with synopsis, genres, score and episode count
- Personal saved library persisted in the browser
- Responsive dark interface for desktop and mobile

## Run locally
```bash
npm install
npm run dev
```

Catalogue data comes from [AniList](https://anilist.co/). Saved titles are stored locally in the browser; account-based sync is not yet included.
